Design Principles

Consistency

One source of truth, one voice and one product. Every screen, component and intersection follows the same rules. Enforced across visually (same colour tokens), behavioural (hover always gold, focus rings 2px), spatial (8px base unit) and typographic (H1 always 48px Geist) consistency

Accessibility

Accessibility is a system property. Embedded in every token, component and guideline from day one. Adheres to WCAG 2.2 AA across four areas: Perceivable (4.5:1 contrast), Operable (keyboard reachable), Understandable (plain-language errors) and Robust (screen reader tested)

Simplicity

Reduce cognitive load. Every element earns its place. No shadows by default, only three font weights (400, 500, 600), a limited colour palette and clean typography. The simpler the interface, the longer the analyst can work effectively

Responsiveness

Seamless adaptation across all screen sizes. On mobile: sidebar hides behind hamburger menu, the cards stack vertically, tables scroll horizontally. On desktop: full sidebar, cards display three to four per row. Same content, same insights but different layouts.
